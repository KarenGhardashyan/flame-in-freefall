**Designated Git Branch:** `dev-lala`  
**Focus Areas:** Web dashboard (Firebase Hosting), 2D/3D flame dynamics visualization, real-time sensor graphs, UX for astronauts & mission control safety console.

---

## 🛠 Working Guidelines for Git
1. **Branch Hygiene:**
   - Always work and preview changes in `dev-lala`:
     ```bash
     git checkout dev-lala || git checkout -b dev-lala
     ```
2. **Synchronizing with Core:**
   - Keep your branch aligned with `main`:
     ```bash
     git fetch origin
     git merge origin/main
     ```
3. **Frontend Staging:**
   - Production web assets must reside in `/frontend` (`index.html`, styles, canvas scripts).
   - Use `LalaMargaryan/` for UI wireframes, mockup assets, and component prototypes.
